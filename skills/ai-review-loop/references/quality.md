# 質量等級與盲比模組

## 適用時機

用戶要求成品「更好」「更細緻」「超越基準」或比舊版好，或成效案例屬主觀判斷（說服力、可讀性、細緻度）而有舊版或基準可比時讀。正確性案例不在此處理，仍按 SKILL.md 定基準。

## 核心原則

- 質量是看結果前定好的有界目標，不是「每輪都要更好」的無底線。達到目標等級即停。
- 等級全部用可觀察的行為或可指出的位置寫，不用 1–5 分，也不用「清晰」「流暢」這類形容詞。
- 不可自己判自己更好：新舊版比較要由獨立或實測核對，自檢最高 PENDING（待獨立核對）。
- 沿用 SKILL.md 三組標籤及必要／參考／候選，不另設標籤。

## 步驟

### 1. 定維度

由 SKILL.md 定基準①（讀者、要做的決定、成功標準）及②（各方最想傳達或最想得到甚麼）推出：每一方最多一個維度，合共不多於三個。維度寫成「該方能否得到他最想得到的東西」，不預設任何固定維度。非衍生成品以①讀者為一方，其他要作決定或受影響的人按情景加。審查中新想到的維度標「候選」。

### 2. 每個維度寫三級

- **未達：** 該方做不到或說不出甚麼。
- **達標：** 該方做得到他最想做到的事，以可觀察行為寫。例如讀者能用自己的話說出會做甚麼決定、對自己有甚麼用；表單用家不用問人就完成填寫；自動化流程的下游用家毋須返查來源就能用產物完成任務。
- **優於基準：** 比基準（用戶範例、同類佳作、舊版）多做到甚麼可指出的事。

等級在看結果前定好，之後要改記入準則變更。

### 3. 定目標等級

按出錯的代價及用途定，寫入目的卡：一般成品以「達標」為必要案例，「優於基準」為參考案例；對外、會重複使用或出錯代價高的成品，可把「優於基準」定為必要案例。用戶已指定的，以用戶為準。

### 4. 計數（輔助證據）

可用：讀者卡住的位置數、讀者解釋不到的術語數、沒有例子或依據的主張數、完成任務所需步數。每個計數附位置，標 SIMULATED 或 CONFIRMED。

不得單獨作證：字數、段落或點列數、形容詞數、「AI 味」評分、判官票數。

### 5. 新舊版盲比

- 判官只收目的卡、各維度及其三級描述、覆蓋清單「對讀者有甚麼用」一欄、角色事實卡，以及兩個未標明新舊的版本。
- 次序對調跑兩次；兩次判斷不一致，記為穩定性 FAIL，不算進步。
- 通過條件：沒有維度退步、至少一個維度明確改善、每項判斷引用位置。
- 判官須為獨立（另一會話或另一模型；同模型須註明）或實測。結果按該維度的目標等級記為必要或參考案例，放入回歸重跑。

## 檢查清單

- [ ] 維度由目的卡及各方推出，不多於三個，沒有套用固定維度？
- [ ] 三級都寫成可觀察行為或可指出的位置？
- [ ] 目標等級在看結果前定好，並寫明理由？
- [ ] 計數有附位置，沒有以字數、票數之類單獨作證？
- [ ] 盲比有對調次序、判官獨立、判斷引用位置？
- [ ] 達到目標等級後有停，沒有繼續打磨？

## 常見錯誤

- 達標後繼續打磨，改出新問題或刪去必要內容。
- 為壓低計數而刪去必要的專業用語。
- 自己判自己更好，或以自己偏好的句式代替讀者行為。
- 等級寫成「更清晰」「更有說服力」，沒有可觀察的行為。

## 簡短測試例子

方法文件改寫成給新手的流程圖。目的卡：新手決定要不要試用。各方：來源一方最想傳達「同一批檢查重跑，揭穿問題只是換了樣子」；讀者最想知道「對我有甚麼用」。維度：讀者能否說出用處；作者重點有否帶走。

- v1 每格對回原文，「不多不少」PASS；但角色（事實卡明確未知：基準、根因、persona）解釋不到四個術語，說不出用處，成效案例 FAIL（SIMULATED）。
- v2 改寫成讀者得到甚麼；獨立會話盲比兩次都判 v2 在兩個維度較好，術語數 4→0，正確性案例沒有退步，記 PASS·獨立（同模型）。已達目標等級，停。
